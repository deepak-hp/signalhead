Signalhead

A traffic light for your AI coding agents.
Stop alt-tabbing to find out whether it's still thinking or has been waiting on you for five minutes.

Red — it stopped and needs you. Permission, a question, a choice.
Yellow — it's working.
Green — it finished and is ready for the next task.
# install
npm install -g signalhead
sig setup

# run it, then wire in your agent

Runs on macOS, Windows and Linux. Drag it anywhere; clicks pass straight through to whatever is underneath. Several agents at once each get a label, and the lamp shows whichever most wants your attention. A slim fuel gauge beside the light tracks how much plan quota or context you have left.

Nothing leaves your machine — the whole thing is a local server on loopback holding the current state of each session, and nothing else.
