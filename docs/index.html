signalhead
Free & open source

A traffic light for your AI coding agents.

Stop alt-tabbing to find out whether it's still thinking or has been waiting on you for five minutes. Glance at the corner of the screen instead.

claude thinking
Red — it stopped and needs you. A permission prompt, a question, a choice.
Yellow — it's working.
Green — it finished and is ready for the next task.

Install

# macOS, Windows, Linux
npm install -g signalhead
sig setup

# run it, then wire in your agent
sig start
sig install claude
View on GitHub npm

Works with any agent

Claude Codeall three lamps Nine lifecycle hooks — sig install claude
Codexall three lamps Reads its own session log — sig watch codex, and drives the fuel gauge from its real quota
Gemini, Aider, Cursor, opencodeall three lamps A watched pseudo-terminal — sig wrap -- gemini
Anything elsewhatever you report One line of shell — sig set waiting --agent deploy

Drag it anywhere; clicks pass straight through to whatever is underneath. Run several agents at once and each gets a label, while the lamp shows whichever most wants your attention. The slim gauge beside the light tracks how much plan quota or context you have left.

Nothing leaves your machine — the whole thing is a local server on loopback holding the current state of each session, and nothing else.
